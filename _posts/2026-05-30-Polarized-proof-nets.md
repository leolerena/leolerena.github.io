## Proof structures.

A **proof structure** is a finite directed graph with additional data, defined as follows:

* A set of vertices.

* A set of directed edges with the following characteristic. 
For a given edge $y$ there is a corresponding unique initial vertex and there *could be* a corresponding unique final vertex. That is vertices are allowed to not have an endpoint but are forced to have a beginning.

* For each vertex there is a unique label in the following set of words $\{ \text{ax, cut, c, w, ?d, !, \text{par}}, \otimes  \}$

* For each edge there is a unique label composed of a formula and either a $+$ or $-$ sign.

### What is a box?
A box is nothing less than a proof structure $\cal B$ that has as conclusions $\Gamma, N$ where $\Gamma$ is a set of input formulas and anti-output formulas and where $N$ is an input formula.
This is a slight generalization from $!$ introduction rule in linear logic.


### What are proof structures?.
A proof structure thus is a graph that has formulas as the labels of their edges but built in a rather naive way.
That is, not every proof structure represents a formula that is valid in linear logic.
The magic of the proof nets is that it suffices to check some strictly graph-theoretical properties in order to guarantee completeness with respect to linear logic.
